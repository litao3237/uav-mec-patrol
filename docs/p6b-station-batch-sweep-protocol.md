# P6b：按 MEC 站点/完整 contact 批次修复通信—计算联合约束

**研发性质：** 本轮 S89–S95 已在 P3/P5/P6 查看过，**不是独立验证**；原论文 `develop`、P1-R 连续资源模型、数值容差、七算法历史曲线全部不变。

## 1. 为什么继续探索批次粒度，而不是继续扩大任务级算子？

P5 已证明原固定 (UAV,MEC) 静态 CPU + 带宽配额在某些看似乐观可行的 D 上发生可证共享资源冲突，但首轮独立新场景 S93–S96 比静态CPU剪枝**没有新增严格恢复，也没有节约额外CVX接口调用**，只发生1次额外安全拒绝事件。对原始预检失败D而言，CPU/BW必要条件可以帮忙拒绝，却不能自动创造新的任务路线。

P6 后续修复在原子四步搜索产生、已经通过 FIFO/EDF 乐观下界的“中间 D”上，依据 joint CPU/BW 绑定**单个任务**尝试改算、跨UAV、改卸载，结果研发 S89–S95 共37个源D中**没有相对P5新增任何严格恢复**；对照“共享站点最重任务”却在 S93/compute×1.5/A130 成功将 **整个 `G_U3_1` 上传接触改往另一MEC E2**，完成原 Stage1+Stage2 严格验收。这揭示：`joint_resource_certificate` 是**站点/虚拟队列/批次**级信息，选择一个绑定任务再修改它可能错过要改变的**整批**，即“诊断粒度不等于修复操作粒度”。

## 2. 冻结预设假设与四个完全相同的动作族

四种新策略都**只能**做“一个原 MEC 上传接触 visit 换到另一个 MEC 的合法物理接触点”；它移动该 batch 的**所有**被卸载任务，保持所有 UAV 任务访问顺序、任务决策和其他物理结构不变，最终每个新 D 仍必须通过原 Stage1/Stage2 完整双审计。与此前混合6个操作族的P6不同，这次隔离**目标接触如何选**的影响。

- `station_all_contacts`：对违反 joint BW/CPU 必要条件的 MEC，检查该站点所有活动接触，按每接触 batch 工作量排序。
- `joint_binding_pairs_2`：先根据模型最低CPU份额与绑定任务选出2个虚拟对中的关键 contact；是真正的资源**任务绑定**控制组。
- `heaviest_batches_2`：仅按候选中每个接触所含全部任务计算工作量选2个 contact；与模型无关的**同动作族、同数量目标**负对照。
- `lexical_contacts_2`：按字符串顺序选2个接触；排除任何先验结构因素是否只是多枚举候选带来收益。

各个选中 contact 最多尝试2个其它MEC合法接触点（按物理航线额外绕行排序），不更改任何原始任务访问路径或决策；全部原离散结构校验、联合必要门槛与原Stage1+Stage2数值验收保留。与 `P5_joint48_baseline` 比较，所有源D和原atomic候选池共用一次、beam2、深4、4s候选生成软上限，后续额外批次修复每臂最多4个原联合冲突种子D、最多100次新结构必要筛选、3s软时间上限、每源**最多3次原CVX Stage1精确求解**。最终验收严格按原Stage1+Stage2，并计入全部额外运行时间。

## 3. 什么结果才支持继续研究？

- 充分观察比对阶段：原P5在源码 SHA256 配对的S89–S95旧研发样本上的2个严格恢复不得被新算子挤掉（原候选优先保留）。
- 证据1：`station_all_contacts` 能否构造旧联合必要界通过的**新离散结构**，并不是只多生成结构。
- 证据2：同一操作下 `joint_binding_pairs_2` 是否优于 `heaviest_batches_2` / `lexical_contacts_2`，否则不能声称资源证书本身提供更好目标定位。
- 证据3：每臂总真实 Stage1调用数、完整条件修复时间是否与严格成功率同步改善，更多候选/加大CVX预算不构成算法增强。
- 如果只证明“检查更多接触偶然修好S93”，停止把这当成论文创新；下一步应考虑站点—批次与接触时序的**联合可操作必要性差分**，而不是把所有 batch 暴力枚举。
- 如有多源稳定开发正结果，必须冻结本分支再用 **S97以后此前全新**场景做首用独立验证，之后对原七算法正式实施真正相同端到端墙钟时间/能耗评估；不得使用S89–S96作为新独立样本。

## 4. 学术背景边界

- IEEE TMC 2024 `10.1109/TMC.2024.3446819` 已有多UAV卸载、资源与轨迹联合优化，因此“多资源联合”本身非新意。
- EJOR 2025 `10.1016/j.ejor.2024.12.009` 已研究局部邻域下用逻辑Benders排除无效结构；当前本方法不是 formal Benders cut。
- Discrete Applied Mathematics 2026 `10.1016/j.dam.2025.07.016` 已有更强 cumulative scheduling energetic reasoning，P5 的向上带宽离散必要界属于特定模型推导，不可宣称全新的基础调度理论。

报告将如实保存成功、失败、数值不确定与实际时间开销；无论结果是否提高，只作为研究方向筛选，不改原论文结果。
