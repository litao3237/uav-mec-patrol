## 1. 这轮与上一轮有什么本质区别？

之前的敏感性实验在每一个物理设置下 **重新运行 B-ALNS/ESI-ALNS**，路线、任务归属、MEC 接触、上传批次与卸载模式可能全部改变，因此无法把总能耗差异直接归因于带宽、计算密度或时限的物理影响。

本轮完全使用上一轮 GitHub Actions **已保存的原始基准离散解**，逐个恢复其路径、接触与卸载决策。随后只改变任务的计算密度、任务截止时间或者 MEC 总带宽；**不做任何离散搜索与重构**，严格重新求解相同离散结构的连续 Stage-1 和 Stage-2，并使用相同约束残差验收。

因此，本轮回答的是：

> **冻结同一条 UAV 路线和同一套接触/卸载决策后，系统物理参数变化是否仍然能得到合格资源方案？**

而不是改哪个参数可以使某个启发式算法能耗更低。

## 2. 最重要的结果：原始离散方案对计算/时延压力极其敏感

下表采用原始 **B-ALNS 基准离散结构**作为被重放对象，报告相同 8 个（4 场景×2 算法种子）实验的两阶段严格合格数。ESI 原始结构在下列压力工况下结论相同（都为 0/8），MEC 带宽缩小时有所区别。

| 物理配置 | 固定 D 乐观可行性预检通过 | 固定 D Stage-1+Stage-2 合格 | 同参数**重新搜索 D** 后合格 |
| --- | ---: | ---: | ---: |
| K50 基准 | 8/8 | 8/8 | 8/8 |
| K50 计算密度 ×1.5 | **4/8** | **0/8** | **8/8** |
| K50 计算密度 ×2.0 | 2/8 | 0/8 | 7/8 |
| K50 真实截止时间 ×0.9 | 1/8 | 0/8 | 7/8 |
| K50 真实截止时间 ×0.8 | 0/8 | 0/8 | 8/8 |
| K80 基准 | 8/8 | 8/8 | 8/8 |
| K80 计算密度 ×1.5 | **7/8** | **0/8** | **4/8** |
| K80 计算密度 ×2.0 | 6/8 | 0/8 | 2/8 |
| K80 真实截止时间 ×0.9 | 2/8 | 0/8 | 3/8 |
| K80 真实截止时间 ×0.8 | 0/8 | 0/8 | 1/8 |

**含义：** 高压下，冻结基准路线、接触和卸载的方案可能无论怎样再分配连续 CPU/带宽都无法满足任务联合约束；重新优化离散结构确实可能恢复合格方案。特别是 K50 计算密度 ×1.5，固定结构 0/8，但重新搜索后 8/8 全部合格。这是**离散结构调整具有实际作用**的直接证据。

注意，失败指的是**当前这一个固定离散方案不可行或严格数值未验收**；绝不意味着整个 UAV-MEC 优化实例被证明无解。

### 一个额外重要现象

在 K80 计算密度 ×1.5，原始基准 D 的 **7/8** 情况通过了“允许每个任务独享最优资源、忽略其它队列”的必要乐观预筛选，但 **0/8** 通过真正的连续资源与队列求解。这直接显示了乐观 task-only 时间下界难以捕获共享 CPU、局部 FIFO、MEC EDF/FIFO 及平均延迟等**联合约束**。

未来高负载可行性修复不能只让若干单任务乐观下界不再违约，还必须考察共享资源和完整调度队列。

## 3. 带宽物理效应不再出现“减少带宽反而使最优能耗降低”的误导

在**相同固定离散结构**下，B-ALNS 原始 D 的合格配对平均：

| K | 带宽 0.5× 时相对基准的 Stage-1 能耗变化 | 带宽 1.5× 时变化 |
| --- | ---: | ---: |
| 50 | **+654.8 J** | **−210.2 J** |
| 80 | **+1275.5 J**（合格样本子集） | **−505.0 J** |

变化符号满足正常物理期望：放松带宽容量不会提高固定结构的理论最优能耗，收紧带宽容量不会降低最优能耗。全部合格的固定结构配对中，没有发现超出冻结数值容差的能耗单调性违例。

而上一轮“每个设置重新运行启发式搜索”的结果有时呈现相反符号，本轮证明那不应被误解为通信物理规律，主要是不同设置导致离散搜索结构不同、有限迭代结果非最优等因素的混合影响。

## 4. 机制建议

这轮已经较好地支持一个研究问题：

**受任务计算量/完成期限变化影响，现有 UAV 路径、上传接触与计算模式的联合结构可能整体不再可行，单纯连续资源重分配无法解决。**

但要判断具体的结构修复机制是否有效，必须使用上一轮保存的失败离散方案，分别测试传统 MEC 贪心修复和由实际违反约束驱动的路径/接触/卸载联合修复，并在两个阶段全部严格合格后才计入修复成功。

**不需要也不应该通过人为更改飞行功率或挑选成功参数，制造算法新颖性。**
