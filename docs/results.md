## 统计原则

算法重复先在场景内平均，再按场景等权。描述性区间按场景 bootstrap；不能把 3 个算法种子当成 3 个独立场景。确定性方法不复制扩充样本。按指标使用合格集合，完整失败记录保留在合格率分母中。

七算法共同有效集合、各方法自身合格集合和 B/ESI 配对子集分别报告，不能混用。80 任务的七算法共同有效比较仅覆盖一个独立场景，而 B/ESI 配对比较可覆盖八个场景。带宽能耗图其他五算法没有合格值，保留缺失和七算法图例，不画虚构曲线或零能耗。

## 主要结果

40 任务的八个共同合格场景中，ESI-ALNS 能耗为 139.155 kJ，相对贪心与遗传基线分别下降 33.89% 和 33.81%。六规模 B/ESI 配对额外节能为 0.291–2.738 kJ。

相同名义端到端预算的平均节能率为 −0.731%（50 任务）与 −0.478%（80 任务），描述性区间均跨 0，尚不能据此声称稳定的等预算优势。超时记录和合格率随原始结果保留。

消融用于考察后强化操作的作用，其目标为 Stage-1 能耗；非 full 配置没有补造 Stage-2 快照。经验参考缺少完整原始资源快照，未在本次重验残差，不是全局最优值或算法最优性证明。

## 文件身份

`archive_manifest.json` 是压缩包与所有原始 JSON 的 SHA-256 清单。`main/frozen_protocol.json`、`extension/frozen_protocol.json` 和 `budget/frozen_source_hashes.json` 保留当次身份。原记录中的源码路径、提交号和环境信息属于审计元数据，不是当前可执行代码依赖。

`figures/data/` 保存最终图值，包含均值、可用区间、样本范围与换算说明。图件按用户指定取消误差棒；这不等于统计区间为零。
