# 六规模五算法完整指标补充协议（2026-09-28）

本轮补齐主性能图所需的“规模×算法×指标”矩阵。新结果独立归档，不与历史固定配置、两规模等预算或机制诊断结果拼接；不修改正式算法接口、搜索实现和物理模型。协议在正式运行前由提交SHA及结构化协议SHA256冻结。

## 1. 矩阵与算法身份

- 任务数K=30、40、50、60、70、80；UAV=5、MEC=2；任务释放时刻为0。
- 每个规模使用S45–52八个场景；随机算法采用A100/101/102三次嵌套重复。沿用场景是为了补齐既有主比较，不称新的未见场景泛化验证，也不宣称八场景已满足某个显著性检验的功效。
- GR-MR、FTR-NM每场景一次；RGA-MR、B-ALNS、ESI-ALNS每场景三次。共48个场景块、528条方法记录，每规模88条。先导为K30/50/80、S45、A100，共15条，单独归档且不并入正式统计。
- 保持原版ESI：100次通用ALNS探索、2轮精英强化；问题算子不进入通用轮盘。B-ALNS使用同一混合运行的探索终点。RGA-MR为真实路线GA，种群16、12代，与历史主比较一致。
- 本轮是固定搜索配置比较，不是各算法等迭代成本或等时间比较。ESI额外CVX与强化耗时完整报告；既有等预算无稳定优势的结论保留。不得将机制诊断Full或Energy-Guided变体冒充论文主算法。

## 2. 执行、资源与计时

同场景所有方法在同一GitHub runner顺序执行；只在场景之间最多8路并行。以固定种子20260928随机化独立搜索组顺序；共享探索的B/ESI为不可拆分的一组。所有方法冷启动搜索缓存，不跨方法共享CVX结果。

使用uv.lock冻结Python依赖、Python 3.13，固定OMP/BLAS/MKL线程数为1，保存平台、代码SHA、运行ID、配置与完整实例哈希。机器差异不能解释为算法速度提升。初始化分别计入：GR为路线种子+MEC修复，FTR为路线种子+最近MEC修复，B/ESI为共享路线种子+MEC修复；RGA的内部初始化已包含在GA调用耗时内。

每个方法最终结构均重新求解Stage-1与Stage-2，保留原始变量、对偶、求解状态、错误及最早时序。Stage-2维持原求解器默认相对能耗容差1e-6，绝对下限1e-5 J；不沿用机制诊断的1e-5相对容差。原始与重建两套时序均使用既有独立残差核验器，数值容差保持不变。先导不能根据收益或通过率放宽容差。

计时分别记录初始化、搜索、最终两阶段重算、独立核验；总交付资源时间为前三项之和，包含核验的总时间另列。B搜索时间为共享探索的实际墙钟时间；ESI搜索时间为完整混合调用，含内部精英CVX检查；共同的最终资源重算单独计入，不能把该重复验收开销隐藏。归档序列化、依赖安装与GitHub排队不计入算法时间。

## 3. 指标与统计

主指标为Stage-1总能耗与Stage-1合格率。补充指标为两阶段同时合格率、Stage-2能耗、平均任务时延、运行内P95时延、最小期限余量、归一化MEC CPU分配、卸载比例、路径长度、接触数、能耗分项及上述时间分项。另记录同结构Stage-2相对Stage-1的CPU与能耗差。

能耗仅使用原状态optimal且保存/重建残差均合格的Stage-1；QoS及CPU要求两阶段都合格。QoS由Stage-2资源重建最早时序，CPU定义为各活动UAV–MEC对分配CPU/所属MEC容量之和，非百分比或实测利用率。P95先在每次运行的任务内计算，再按场景汇总。数值失败不是数学不可行性证明，失败不填零，Stage-1回退不冒充Stage-2成功。

发布三种明确区分的统计：各方法自身有效集合的条件均值；五方法共同有效的场景/种子块比较；ESI与各基线共同有效块上的配对差（ESI减基线）。确定性基线可被同场景随机重复复用进行配对，但不增加独立场景数。先对同场景重复平均，再场景等权；同时保留运行等权值。每个指标列有效数、独立场景数及缺失，少量共同场景不作总体排名。

场景bootstrap固定10000次、种子20260928，95%分位区间仅作描述；少于2场景不生成区间。保存全体失败、零变化和负结果，不按图形完整程度排除规模。已有数据不能保证每个算法在每个规模都有有效QoS柱；空缺须标明原因，不能通过放宽验收凑齐。

## 4. 技术验收与自动启动

入口：`experiments/run_multiscale_metrics.py`；离线核验与统计：`experiments/aggregate_multiscale_metrics.py`；工作流：`.github/workflows/multiscale_metrics.yml`。

正式dispatch首先运行测试，再执行三个先导场景块；完整性、算法身份、共享探索、原始快照、重建残差和统计程序通过后自动运行48个正式场景块。先导门槛是技术完整性，不是效果方向、显著性或求解合格率。执行错误使作业失败并保留已完成数据；数值未合格正常归档。汇总拒绝缺失/重复记录、混合提交/配置/依赖和被改写的有效性判定。

正式归档含528条方法记录的原始JSON、源文件SHA256、协议、统计JSON与逐记录CSV。新图沿用横轴K的六个真实取值、纵轴指标，颜色固定对应五方法；只有在结果核对后才决定可进入主文的指标。所有历史图稿和Word原件保持可追溯。
