# 最终图件与源数据

`pdf/`、`svg/`、`png/`、`tiff/` 各 23 幅，均保留最终确认稿的原始字节。图 3、7、8、12、17 使用最近确认的轴刻度和图型；图 7/8 为分组柱状，全部无局部放大。图 1/2 保留原模型和算法框架布局。

`data/` 中 20 张 CSV 与实验图一一对应，`data/map/` 为地图源资产。`figure_data_map.json` 说明数据位置与变换；`manifest.json` 验证全部已确认文件。SVG 为可编辑矢量源，PDF 为论文排版首选。

运行 `python experiments/plot_figures.py --output-dir outputs/figures` 可重建 20 幅实验图并复制图 1/2/19 的冻结资产。该入口不覆盖此目录。重新生成受系统字体影响，供数据与绘图复现；如需排版字节完全一致，使用此处冻结的图件。

图值均来自冻结实验；不使用偏移、抖动、平滑或局部放大。柱状图包含零基线；空值不等同于零。置信区间保留在 CSV，按指定视觉样式不画误差棒。所有重建图为单坐标区，不存在多面板对齐问题。
